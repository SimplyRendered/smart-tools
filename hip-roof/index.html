Every face has the same pitch, so the hips run at 45° in plan and the ridge is the length minus the width. A square plan gives a pyramid roof with no ridge. Jack rafters run from the eaves up to a hip; the list is for one face next to one hip, and every hip has the same set on both sides.

Free tool · @smart_tools_every_week · simplyrendered.github.io/smart-tools · built with ClaudeEqual-pitch hip roof on a rectangle, hips at 45° in plan (first-principles geometry, as in any carpentry roofing text): run R = half the eaves width, rise = R·tan θ, common rafter = R ÷ cos θ, hip plan = R·√2, hip true length = √(2R² + rise²), hip pitch = atan(rise ÷ R√2), backing angle: tan b = sin(hip pitch), jack rafter = its plan run ÷ cos θ, roof area = plan area ÷ cos θ. Lengths are to the centre lines; the cut length deducts half the hip thickness. Check sizes with a structural engineer.
