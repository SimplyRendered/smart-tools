# Smart Tools Every Week

Free web tools for architects and students, built with Claude. A new tool every week on Instagram [@smart_tools_every_week](https://instagram.com/smart_tools_every_week).

Live: https://simplyrendered.github.io/smart-tools/

| No. | App | Use online | Download |
|---|---|---|---|
| T-01 | Sun Path & Shadow | [open](https://simplyrendered.github.io/smart-tools/sun-shadow/) | [sun-shadow.html](sun-shadow/sun-shadow.html) |
| T-02 | Vastu Grid Overlay | [open](https://simplyrendered.github.io/smart-tools/vastu-grid/) | [vastu-grid.html](vastu-grid/vastu-grid.html) |
| T-03 | Sheet Fit & Scale | [open](https://simplyrendered.github.io/smart-tools/sheet-scale/) | [sheet-scale.html](sheet-scale/sheet-scale.html) |

Each app is a single self-contained HTML file. Download it and open it in any browser; it works offline.
