Free tool · @smart_tools_every_week · simplyrendered.github.io/smart-tools · built with ClaudeOrthographic axonometric: plan turned θ, viewed from φ above the ground. Axis angle above horizontal: x = atan(tan θ · sin φ), y = atan(sin φ / tan θ); scales kx = √(cos²θ + sin²θ·sin²φ), ky = √(sin²θ + cos²θ·sin²φ), kz = cos φ (descriptive geometry, first principles). Isometric: θ 45°, φ 35.26°, every scale 0.816 (an isometric drawing uses full size, 1.22× the true projection). Oblique: plan or front face kept true, the third axis at your angle and scale (cavalier 1, cabinet ½).
