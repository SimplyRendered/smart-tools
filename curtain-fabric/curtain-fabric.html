Track width: usually the window plus 150 to 300 mm each side so the curtains stack off the glass. Return: the bit that wraps from the track end back to the wall. Overlap: each leading edge passes the centre by this much. Set the repeat to 0 for plain fabric. Lining uses the same widths, cut 150 mm shorter, with no repeat. Quick rule: track × fullness ÷ roll width, rounded up, × (drop + 300 mm).

Fullness by heading and all allowances are typical values: ask your curtain maker for theirs.
